# Reqchat

Welcome to reqchat project! <br>

An LLM trained to answer questions about the requirements of a system. The model is inspired and created based on the nanoGPT and nanochat project of Andrej Karpathy. 

Requirement engineering involves eliciting and managing well-formed requirements that becomes a problem-space of a projects objective. Within RE, requirement elicitation faces challenges due to stakeholder inexperience, fragmented knowledge, and other process uncertainities. We aim to fine-tune a LLM through well-formed requirement datasets and specific IEEE standards that are intended to guide the requirement elicitation process.
